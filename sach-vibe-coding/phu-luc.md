# Phụ Lục A: Bảng Từ Vựng Kỹ Thuật — Giải Thích Đơn Giản

> *Bạn không cần nhớ tất cả — chỉ cần lật lại trang này mỗi khi gặp thuật ngữ lạ.*

| # | Thuật ngữ | Phát âm | Giải thích dễ hiểu |
|---|-----------|---------|---------------------|
| 1 | **API** | Ê-pi-ai | "Người liên lạc" giữa website và server — khi bạn bấm nút, API gửi yêu cầu đến server |
| 2 | **Backend** | Bách-en | Phần "hậu trường" — xử lý logic, dữ liệu, bảo mật (người dùng không thấy) |
| 3 | **Build** | Biu | Đóng gói code thành sản phẩm hoàn chỉnh, sẵn sàng chạy trên internet |
| 4 | **Commit** | Cóm-mít | "Save game" — lưu lại một phiên bản code tại thời điểm hiện tại |
| 5 | **Component** | Com-pâu-nần | Một "mảnh ghép" giao diện (VD: nút bấm, thanh menu, card sản phẩm) |
| 6 | **CSS** | Xì-ét-ét | "Hộp sơn" — quy định màu sắc, kích thước, bố cục cho website |
| 7 | **Database** | Đây-tà-bết | "Tủ hồ sơ thông minh" — lưu trữ dữ liệu (bài viết, sản phẩm, user...) |
| 8 | **Dependencies** | Đì-pen-đần-xi | "Nguyên liệu" — các thư viện code người khác viết sẵn mà dự án bạn cần dùng |
| 9 | **Deploy** | Đì-ploi | Đưa website từ máy cá nhân lên internet để ai cũng truy cập được |
| 10 | **DNS** | Đi-en-ét | "Danh bạ điện thoại" của internet — chuyển tên miền thành địa chỉ IP |
| 11 | **DOM** | Đom | Cấu trúc cây của trang web — AI dùng nó để biết cần sửa phần nào |
| 12 | **Framework** | Phrâim-uốc | "Bộ LEGO có sẵn" — công cụ viết code nhanh hơn (React, Vue, Angular...) |
| 13 | **Frontend** | Phrốn-en | Phần "sân khấu" — giao diện mà người dùng nhìn thấy và tương tác |
| 14 | **Git** | Ghít | "Time machine cho code" — lưu lại lịch sử thay đổi, có thể quay lại bất kỳ lúc nào |
| 15 | **GitHub** | Ghít-hấp | "Kho lưu trữ online" cho code — như Google Drive nhưng cho lập trình |
| 16 | **HTML** | Ếch-ti-em-eo | "Bộ khung xương" — cấu trúc cơ bản của trang web (text, hình, link...) |
| 17 | **IDE** | Ai-đi-i | "Phòng làm việc" cho lập trình — nơi viết code, chạy lệnh, xem kết quả |
| 18 | **JavaScript** | Gia-va-xcrip | "Bộ não" — ngôn ngữ lập trình làm website hoạt động (bấm nút, animation...) |
| 19 | **JSON** | Giây-sần | "Bảng kê" dữ liệu — định dạng phổ biến để lưu và truyền thông tin |
| 20 | **localhost** | Lâu-cồ-hốt | "Máy tính của bạn" — khi website chạy ở localhost nghĩa là chỉ bạn thấy |
| 21 | **MySQL** | Mai-ét-cu-eo | Một loại database phổ biến, miễn phí, dễ dùng |
| 22 | **Node.js** | Nốt-giây-ét | "Bộ động cơ" — cho phép chạy JavaScript bên ngoài trình duyệt |
| 23 | **npm** | En-pi-em | "Cửa hàng" tải package — gõ `npm install` để tải thư viện về dự án |
| 24 | **Package** | Pác-kịch | "Gói nguyên liệu" — thư viện code có sẵn ai đó viết, bạn chỉ cần tải và dùng |
| 25 | **Port** | Pọt | "Cánh cửa" — số cổng website chạy (VD: localhost:**5173**) |
| 26 | **Prompt** | Prôm | "Lời yêu cầu" bạn gửi cho AI — càng chi tiết càng tốt |
| 27 | **React** | Ri-ắc | Framework phổ biến nhất thế giới để xây giao diện website |
| 28 | **Responsive** | Rì-spon-xịv | Website tự co giãn đẹp trên mọi kích cỡ màn hình (điện thoại → máy tính) |
| 29 | **Route/Routing** | Rau | "Bản đồ" website — quy định URL nào dẫn đến trang nào |
| 30 | **SEO** | Ét-i-âu | Tối ưu hóa để Google tìm thấy website bạn |
| 31 | **Server** | Sơ-vơ | Máy tính chạy 24/7 trên internet, phục vụ website cho mọi người |
| 32 | **SSH** | Ét-ét-ếch | "Điều khiển từ xa" — kết nối vào server/VPS để quản lý |
| 33 | **SSL/HTTPS** | Ết-ết-eo | "Khóa bảo mật" — mã hóa dữ liệu giữa người dùng và website |
| 34 | **Terminal** | Tơ-mi-nồ | "Hộp lệnh" — nơi bạn gõ lệnh cho máy tính thực hiện |
| 35 | **TypeScript** | Thai-xcrip | JavaScript phiên bản "nâng cấp" — an toàn hơn, ít lỗi hơn |
| 36 | **UI/UX** | Iu-ai/Iu-ét | Giao diện người dùng (UI) và trải nghiệm người dùng (UX) |
| 37 | **Vercel** | Vơ-xeo | Platform deploy website miễn phí, dễ nhất thế giới |
| 38 | **Vite** | Vít | Build tool siêu nhanh cho dự án web hiện đại |
| 39 | **VPS** | Vi-pi-ét | Máy tính ảo thuê trên internet, có toàn quyền kiểm soát |

## 🏗️ Khởi Tạo Dự Án (Prompt 1-5)

**#1. Tạo website portfolio**
> *"Em tạo dự án website portfolio cá nhân: React + Vite + TypeScript + Tailwind CSS. Light theme, font Inter, tối giản. Hero section có avatar tròn, tên [TÊN], subtitle [CHỨC DANH]. Responsive. Có animation fade-in. Chạy thử luôn."*

**#2. Tạo website bán hàng**
> *"Em tạo website bán hàng online cho cửa hàng [TÊN CỬA HÀNG]. Có trang chủ với banner, trang sản phẩm dạng grid, giỏ hàng, form đặt hàng. Theme ấm áp, friendly. React + Vite."*

**#3. Tạo blog**
> *"Em tạo blog cá nhân với theme dark, font serif cho nội dung. Trang chủ hiển thị 10 bài mới nhất dạng card. Có sidebar với categories và tags. React + Vite + Tailwind."*

**#4. Tạo landing page**
> *"Em tạo landing page cho sản phẩm [TÊN SẢN PHẨM]. Gồm: hero section với headline mạnh, features (3 cột icon + text), testimonials, pricing table, CTA button, footer. One-page scroll, modern design."*

**#5. Tạo trang cộng đồng**
> *"Em tạo trang cộng đồng cho nhóm [TÊN NHÓM]. Có: giới thiệu nhóm, danh sách thành viên dạng grid avatar, lịch events, form đăng ký tham gia, link Facebook group."*

## 🎨 Thiết Kế Giao Diện (Prompt 6-15)

**#6. Header / Navbar**
> *"Em tạo navbar fixed trên cùng. Trái: logo text '[TÊN]'. Phải: menu [MỤC 1, MỤC 2, MỤC 3]. Khi scroll: backdrop-blur. Mobile: hamburger menu slide từ phải."*

**#7. Hero Section**
> *"Em tạo hero section full-height: avatar tròn giữa (ring border mỏng), tên font 7xl, subtitle font lg, 2 nút CTA bo tròn. Animation stagger: avatar → tên → subtitle → buttons."*

**#8. About Section**
> *"Em tạo section About: tiêu đề 'Về Tôi', 2 cột (text trái, skill tags phải). Tags dạng badge bo tròn, nhiều màu soft. Trên mobile: stack thành 1 cột."*

**#9. Grid Cards**
> *"Em tạo grid 3 cột hiển thị [SẢN PHẨM/DỰ ÁN]. Mỗi card: thumbnail 16:9, tiêu đề đậm, mô tả 2 dòng, tags nhỏ. Hover: translateY(-4px) + shadow. Tablet: 2 cột. Mobile: 1 cột."*

**#10. Dark Mode Toggle**
> *"Em thêm nút toggle dark/light mode ở navbar (icon sun/moon). Khi click: toàn website chuyển theme mượt mà. Lưu preference vào localStorage."*

**#11. Footer**
> *"Em tạo footer: chia 3 cột (About, Links, Social). Row dưới: copyright '© 2026 [TÊN]'. Nền tối hơn một chút so với body."*

**#12. Form Liên Hệ**
> *"Em tạo contact form đẹp: 3 field (Họ tên, Email, Tin nhắn), nút Gửi (nền đen, chữ trắng, bo tròn). Validation: email đúng format. Submit: hiện toast 'Gửi thành công!'."*

**#13. Testimonials / Đánh Giá**
> *"Em tạo section đánh giá dạng carousel: mỗi card có avatar, tên, chức danh, nội dung đánh giá (italic, trong dấu ngoặc kép). Auto-slide mỗi 5 giây. Dots navigation bên dưới."*

**#14. Timeline**
> *"Em tạo section timeline dọc hiển thị [KINH NGHIỆM / SỰ KIỆN]: mốc thời gian bên trái, nội dung bên phải, đường line nối các mốc. Alternate trái-phải trên desktop."*

**#15. Pricing Table**
> *"Em tạo bảng giá 3 gói: [BASIC], [PRO], [PREMIUM]. Mỗi cột: tên gói, giá, danh sách features (✓/✗), nút CTA. Gói giữa highlight (border accent, badge 'Phổ biến nhất')."*
