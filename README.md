# Vy Thiên Hùng - Personal Blog

Website cá nhân của Vy Thiên Hùng.

**URL**: [vythienhung.com](https://vythienhung.com)

## Tech Stack

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Framer Motion

## Development

```sh
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

```sh
npm run start
```

This will build and serve the app on port 45455.
